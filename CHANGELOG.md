## 0.1.0

### Added

- PostgreSQL SQL backups streamed through gzip into private timestamped files.
- Connection configuration through `PG*` variables or `DATABASE_URL`.
- Cobra CLI with branded help and structured logging.
- Build version and commit reporting with `--version`.
- Optional backup deadlines with `--timeout` and partial-file cleanup.
- Linux and macOS release archives for amd64 and arm64, with SHA-256 checksums.

GitHub release notes are generated from the Git history for each tag. Published versions and their artifacts appear in [GitHub Releases](https://github.com/Nardeo-org/nardeo-backup/releases).
